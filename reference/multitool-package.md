# multitool: Run Multiverse Style Analyses

Run the same analysis over a range of arbitrary data processing
decisions. 'multitool' provides an interface for creating alternative
analysis pipelines and turning them into a grid of all possible
pipelines. Using this grid as a blueprint, you can model your data
across all possible pipelines and summarize the results.
