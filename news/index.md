# Changelog

## multitool (development version)

## multitool 0.1.5

CRAN release: 2025-09-03

- Added subgroup functionality with
  [`add_subgroups()`](https://ethan-young.github.io/multitool/reference/add_subgroups.md)
- Updated `show_code_*` functions with an option to run code in the
  console
- Updated
  [`create_blueprint_graph()`](https://ethan-young.github.io/multitool/reference/create_blueprint_graph.md)
  to visualize subgroups if they exist
- Updated `reveal_*` functions to show subgroup specs, if they exist
- Fixed an issue with `add_parameters()`
- Added a parallel option for `run_multiverse()` via
  [furrr](https://github.com/futureverse/furrr)
- Calculate standardized coefficients by default
